# AI JOB BATTLE v0.1

スマートフォン向け、90秒・5ラウンドの「AIのミスを見破れ！」ゲーム。**実際に動くNext.jsアプリ**です。

## 遊び方

- AIが作った仕事の成果物を読み、3択で問題点を指摘
- 正解すると得点。時間が残っているほどボーナス
- 12問から毎回5問をランダム出題
- 90秒で終了。結果と最高記録を表示

## 起動

Node.js 20以上を用意し、ターミナルで以下を実行。

```bash
npm install
npm run dev
```

ブラウザで http://localhost:3000 を開きます。

## スマホでテスト

同じWi-Fiのスマホからアクセスする場合：

```bash
npm run dev -- --hostname 0.0.0.0
```

PCのローカルIPアドレスを調べ、スマホのブラウザで `http://PCのIP:3000` にアクセスします。ファイアウォールの許可が必要な場合があります。

## Vercelに公開

1. このフォルダをGitHubリポジトリへpush
2. Vercelで **Add New → Project** を選択
3. GitHubリポジトリを選び、Framework Preset: **Next.js** のまま **Deploy**
4. 表示された公開URLをスマホで開く

## 重要な仕様

- **AI APIは未接続**。12問は事前作成された固定問題で、実行時のAI生成はありません。
- スコアはゲーム用。AI業務代行率や削減時間を示すものではありません。
- 最高記録はブラウザのlocalStorageに保存。サーバーDBやログインは不要です。
- 課金、ランキング、ユーザーアカウントは未実装です。
- 次の拡張はAIによるミッション生成（サーバーAPIルート、認証、使用回数制限、品質検証）を推奨します。

## ファイル構成

- `app/page.tsx`: ゲーム画面、タイマー、得点、結果
- `app/globals.css`: スマホ向けスタイル
- `app/layout.tsx`: 日本語設定、ページメタ情報
- `lib/missions.ts`: 問題12問と解説
